## 背景

README の基本原則は音声収集と AI による詐欺判定を避けることを明示している。

## 記録する判断

README に記載された、録音せず音声をサーバへ送らない、番号を通知して家族が判断する基本方針を記録する。

この ADR は既存資料・コードの判断を整理した遡及記録であり、今回の整備で新しい設計を承認・実装したものではない。設計資料にある将来案の実装完了は断定しない。

## 代替案と判断の根拠

上記の根拠資料に残る理由を記録する。比較した代替案・却下理由が資料にない場合は NEEDS_CONFIRMATION とし、後から選定経緯を作らない。

## 影響と制約

番号の共有範囲と保持を定義する必要がある。将来案の自動切断は基本原則との整合性が未確定で、この ADR では承認しない。

## 再検討する条件
